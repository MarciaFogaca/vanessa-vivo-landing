Landing Page — Vanessa de Mendonça | Vivo Empresas
Landing page de apresentação comercial de Vanessa de Mendonça, executiva B2B, voltada a empresas interessadas em soluções de conectividade e tecnologia.
Sobre o projeto
O site apresenta soluções empresariais, diferenciais do atendimento consultivo, informações profissionais e um formulário de contato que prepara uma mensagem para envio pelo WhatsApp.
Aviso: site de apresentação e atendimento de parceira comercial independente. Não é um portal institucional oficial da Vivo.

Funcionalidades
- Layout responsivo para desktop, tablet e celular.
- Navegação por seções com rolagem suave e indicação da seção ativa.
- Apresentação de soluções empresariais, como telefonia, internet, PABX, cloud, segurança digital e IoT.
- Globo digital decorativo com efeitos visuais.
- Formulário de contato com validação de dados e CNPJ obrigatório.
- Preparação de mensagem personalizada e abertura do WhatsApp para contato.
- Botão flutuante de acesso ao WhatsApp.
Importante: o formulário não grava os dados em banco de dados. O envio da mensagem depende da confirmação do usuário no WhatsApp.
Tecnologias
- React
- TypeScript
- Vite
- Tailwind CSS
- React Hook Form
- Zod
- Lucide React
Como executar localmente
Pré-requisito: Node.js e npm instalados.
npm install
npm run dev
Abra no navegador o endereço informado pelo Vite no terminal.
Build de produção
npm run build
Os arquivos de produção são gerados na pasta dist/.
Publicação
O projeto pode ser publicado em plataformas de hospedagem para aplicações front-end, como a Vercel, conectando o repositório do GitHub.

Configuração habitual para Vite:
- Build command: npm run build
- Output directory: dist
Privacidade
O formulário solicita informações de contato e dados da empresa para preparar uma mensagem no WhatsApp. Antes de publicar, revise o aviso de privacidade, o tratamento dos dados e os links de contato.
